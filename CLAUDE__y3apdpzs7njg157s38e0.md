## Проект «אור השפע» (Or HaShefa)
Полуавтоматическая торговля фьючерсом BTCUSDT (Binance USDⓈ-M): система выдаёт сигнал, человек подтверждает.

- Страница: https://grinwald77.github.io/y3apdpzs7njg157s38e0/ — репозиторий `Grinwald77/y3apdpzs7njg157s38e0` (ПУБЛИЧНЫЙ, GitHub Pages), один файл `index.html`.
- Воркер: https://wohjadjm4gr5m0skzvvp.egal-greenwald.workers.dev — репозиторий `Grinwald77/Or-aShefa-worker` (приватный). Push в `main` → GitHub Actions → `wrangler deploy`.
- База: Cloudflare D1 `trader-journal`, привязка `DB` (таблицы trades, auth_fail, meta создаются автоматически).
- Cron воркера раз в минуту: свечи из Bybit → OKX → Kraken → Bitstamp → data-api.binance.vision, сигналы и отчёт каждые 30 минут в Telegram.

### Почему так устроено (не ломать)
- Binance блокирует IP Cloudflare (403), поэтому воркер только считает и ПОДПИСЫВАЕТ запросы (Ed25519), а отправляет их браузер.
- REST из браузера разрешён (CORS) только для GET balance/positionRisk/userTrades/dual и POST leverage/marginType.
- `/fapi/v1/order`, algoOrder, openAlgoOrders идут через WebSocket API: демо `wss://testnet.binancefuture.com/ws-fapi/v1`, реальный `wss://ws-fapi.binance.com/ws-fapi/v1`.
- Стоп и тейк — условные ордера algoOrder (CONDITIONAL, closePosition, MARK_PRICE), их id хранятся в meta `algos`.
- Сейчас ДЕМО-счёт (`BINANCE_FUTURES_BASE_URL` по умолчанию https://demo-fapi.binance.com).

### Секреты и переменные — только в панели Cloudflare, НИКОГДА в репозиториях
Секреты: APP_PASSWORD, BINANCE_API_KEY, BINANCE_PRIVATE_KEY, TELEGRAM_BOT_TOKEN.
Переменные: ALLOWED_ORIGIN, PAGE_URL, WORK_CAPITAL (50), RISK_PCT (10), SIZING (house), LIMIT_BARS (3), WEEKLY_LOSS_PCT, BINANCE_FUTURES_BASE_URL, CONFIRM_LIVE.

### Система 1 (работает вживую на демо)
- Тренд по EMA (20/50/100/200), пробой канала Дончиана 20 свечей на закрытии свечи; таймфреймы 1m/15m/30m/1h/2h/4h.
- Вход лимиткой (GTD) на уровне пробоя, действует 3 свечи; стоп 1.5×ATR(14), цель 2R; плечо 100x, cross, One-way.
- Размер: 10% от капитала серии + прибыль серии (старт $50); при ×2 — новая серия, при убытке — сброс.
- Блокировка на реальном счёте: недельный убыток > WEEKLY_LOSS_PCT → пауза 3 рабочих дня. Пароль: на демо без блокировки, на реальном 5 ошибок → 5 минут.

### Система 2 (MACD) — пока только в тестере
- Ранний сигнал: столбики гистограммы в противоположной зоне уменьшаются; подтверждение: линии пересеклись, гистограмма сменила зону. Фильтр объёма — объём выше среднего за 20 свечей.
- ВСЁ считается в деньгах от депозита, не в пунктах/марже/цене: цель +X% к депозиту; первый стоп = 15% от цели; при +10% к депозиту стоп на +5%, дальше каждые +10% подтягивают стоп ещё на 10%.
